## 4. Dokumentasi Kegiatan Workshop

### A. Rangkuman Materi

#### 1. Prompt Engineering

Prompt Engineering merupakan cara menyusun instruksi atau perintah yang diberikan kepada AI agar menghasilkan jawaban sesuai dengan kebutuhan pengguna. Dalam materi ini, saya belajar bahwa memberikan perintah kepada AI tidak cukup hanya dengan menjelaskan apa yang ingin dibuat. Kita juga perlu memberikan konteks dan arahan yang jelas agar hasil yang diberikan lebih sesuai dengan tujuan.

Salah satu hal yang dibahas adalah struktur prompt yang terdiri dari empat bagian utama:

- **Role:** Menentukan peran yang harus dijalankan oleh AI.
- **Task:** Menjelaskan tugas atau pekerjaan yang ingin dilakukan.
- **Context:** Memberikan latar belakang dan informasi yang dibutuhkan.
- **Format:** Menentukan bentuk hasil yang diharapkan.

Dari materi ini, saya memahami bahwa kualitas jawaban AI juga dipengaruhi oleh bagaimana kita menyusun instruksi yang diberikan.

#### 2. Pengenalan Git

Git merupakan sebuah Version Control System (VCS) yang digunakan untuk mencatat dan melacak perubahan pada file dalam suatu proyek. Dengan menggunakan Git, pengguna dapat mengetahui perubahan yang telah dilakukan, menyimpan riwayat pekerjaan, serta mengelola perkembangan proyek dengan lebih teratur.

Beberapa istilah dasar yang dipelajari dalam Git antara lain:

- **Working Directory:** Tempat file proyek dikerjakan dan diubah.
- **Staging Area:** Tempat untuk menyiapkan perubahan sebelum disimpan melalui commit.
- **Commit:** Proses menyimpan catatan perubahan ke dalam repository Git.
- **Branch:** Cabang pengembangan yang memungkinkan pengguna mengerjakan perubahan secara terpisah.

#### 3. Pengenalan GitHub

GitHub merupakan platform berbasis web yang digunakan untuk menyimpan repository Git secara online. Selain sebagai tempat penyimpanan, GitHub juga dapat digunakan untuk mendukung kolaborasi dan pengelolaan proyek. Melalui GitHub, file proyek dapat diakses secara daring sesuai dengan pengaturan visibilitas repository. Salah satu jenis visibilitas yang dipelajari adalah Public, yaitu repository yang dapat dilihat oleh orang lain.

#### 4. Perbedaan Git dan GitHub

Meskipun memiliki nama yang hampir sama, Git dan GitHub sebenarnya mempunyai fungsi yang berbeda. Git merupakan alat untuk melacak serta mengelola perubahan file secara lokal pada komputer. Sementara itu, GitHub merupakan platform online yang digunakan untuk menyimpan repository Git dan mendukung kolaborasi. Keduanya saling berkaitan karena Git dapat digunakan untuk mengelola proyek sebelum perubahan tersebut dikirim dan disimpan ke GitHub.

#### 5. Perintah Dasar Git

Dalam workshop, diperkenalkan beberapa perintah dasar yang digunakan untuk mengelola repository.

| Perintah | Fungsi |
|---|---|
| `git init` | Membuat repository Git baru pada folder proyek. |
| `git add .` | Memasukkan perubahan file ke staging area. |
| `git commit -m "pesan"` | Menyimpan catatan perubahan. |
| `git push origin main` | Mengirim perubahan ke repository GitHub. |
| `git pull origin main` | Mengambil dan menggabungkan perubahan dari repository remote. |
| `git branch -M main` | Mengganti nama branch aktif menjadi main. |

Perintah-perintah tersebut merupakan dasar yang perlu dipahami sebelum mulai menggunakan Git dan GitHub dalam mengelola sebuah proyek.

#### 6. Alur Kerja Git dan GitHub

Secara umum, penggunaan Git dan GitHub memiliki beberapa tahapan. Dimulai dari membuat atau menyiapkan folder proyek, menginisialisasi Git, memasukkan perubahan ke staging area, melakukan commit, menghubungkan repository lokal dengan GitHub, kemudian melakukan push.

Alur tersebut membantu pengguna menyimpan perkembangan proyek secara bertahap. Ketika terdapat perubahan baru, pengguna dapat kembali melakukan add, commit, dan push agar perubahan tersebut juga tersimpan di GitHub.

### B. Poin Penting dan Pengetahuan Baru

Dari seluruh materi yang disampaikan selama workshop, ada beberapa hal yang menjadi pengetahuan baru bagi saya.

**1. AI dapat membantu proses pembuatan aplikasi.**

Sebelumnya, saya menganggap bahwa membuat sebuah aplikasi atau website harus sepenuhnya memahami bahasa pemrograman terlebih dahulu. Namun, melalui materi Prompt Engineering, saya mulai memahami bahwa AI dapat dimanfaatkan sebagai alat bantu dalam proses tersebut. Meskipun begitu, kita tetap perlu memahami kebutuhan dan memeriksa hasil yang diberikan AI.

**2. Memberikan instruksi yang jelas kepada AI itu penting.**

Saya belajar bahwa prompt yang terlalu singkat atau kurang memiliki konteks dapat menghasilkan jawaban yang tidak sesuai harapan. Karena itu, memberikan informasi mengenai tujuan, kebutuhan, dan format hasil menjadi hal yang penting.

**3. Git membantu mengelola perubahan file.**

Saya baru mengetahui bahwa perubahan dalam sebuah proyek dapat dicatat menggunakan Git. Hal ini membuat proses pengerjaan lebih teratur karena setiap perubahan dapat disimpan sebagai riwayat.

**4. Git dan GitHub memiliki fungsi yang berbeda.**

Keduanya sering disebut secara bersamaan, tetapi ternyata Git dan GitHub bukanlah hal yang sama. Git digunakan untuk mengelola perubahan secara lokal, sedangkan GitHub menjadi tempat penyimpanan repository secara online.

**5. Repository bukan hanya tempat menyimpan kode.**

Saya juga memahami bahwa repository dapat digunakan untuk menyimpan dokumentasi, catatan pembelajaran, dan berbagai informasi mengenai suatu proyek. Karena itu, penyusunan file dan dokumentasi yang rapi menjadi hal yang perlu diperhatikan.

**6. Dokumentasi merupakan bagian penting dalam pengerjaan proyek.**

Melalui materi ini, saya menyadari bahwa proses belajar maupun pengerjaan proyek sebaiknya tidak hanya dilakukan, tetapi juga dicatat. Dokumentasi dapat membantu kita mengingat apa yang sudah dikerjakan dan memudahkan orang lain memahami isi suatu repository.
